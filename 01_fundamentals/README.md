# Module 01: Spark SQL & DataFrame Fundamentals

This module covers the core distributed mechanics of Apache Spark DataFrames.

## What You'll Learn:
- Initializing a local `SparkSession` with optimized memory and shuffle partitions.
- Creating DataFrames with explicit schemas vs. schema inference.
- Filtering, column derivations, and null handling.
- Aggregations and grouping at scale.
- Inspecting Catalyst Optimizer physical execution plans with `explain()`.

## Files:
- `01_dataframe_basics.py`: Hands-on script demonstrating fundamental DataFrame operations and plan inspection.

## Run this lab:
```bash
uv run python 01_fundamentals/01_dataframe_basics.py
```
